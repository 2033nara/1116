# 대한민국 행정안전부 대국민 안내 포털

일반 국민이 행정안전부(MOIS)의 주요 업무와 생활 밀착형 공공 서비스를 한눈에 이해할 수 있도록 제작된 반응형 웹 포털입니다. 최신 **Google Gemini API**를 탑재하여 국민들이 궁금한 행정/안전 민원을 일상 언어로 물어보면 알기 쉽게 답변해 줍니다.

---

## 🌟 주요 구성 요소

1. **행안부 4대 핵심 업무 영역 소개**
   - **재난안전 총괄**: 긴급재난문자, 풍수해·지진 대비, 안전신문고
   - **디지털플랫폼정부**: 정부24, 모바일 신분증(운전면허증/주민등록증), 국민비서 구삐
   - **지방자치 & 균형발전**: 지방재정/지방교부세, 고향사랑기부제, 지역소멸 대응
   - **정부 혁신 & 공공관리**: 공공데이터 무료 개방(data.go.kr), 주민등록제도

2. **국민 생활 속 대표 서비스 원스톱 링크**
   - 정부24 (`gov.kr`)
   - 안전신문고 (`safetyreport.go.kr`)
   - 국민비서 구삐 (`ips.go.kr`)
   - 국민재난안전포털 (`safekorea.go.kr`)
   - 공공데이터포털 (`data.go.kr`)
   - 고향사랑e음 (`ilovegohyang.go.kr`)

3. **Gemini API 기반 AI 스마트 도우미 (@[plugin:gemini-api])**
   - 질문 예시: *"주민등록등본 어떻게 발급받나요?"*, *"도로가 파손됐을 때 어디에 신고하나요?"*, *"모바일 신분증 법적 효력이 있나요?"*
   - **하이브리드 모드**:
     - **Gemini API 연동 모드**: Gemini 2.5 Flash 모델을 통한 실시간 고지능 질의응답
     - **오프라인 내장 지식베이스 모드**: API 키가 없어도 주요 핵심 질문에 대한 즉시 답변 제공

---

## 🚀 실행 방법

별도의 서버 설치 없이 브라우저에서 바로 실행할 수 있습니다.

1. `index.html` 파일을 더블클릭하거나 웹 브라우저(Chrome, Edge 등)로 엽니다.
2. 페이지 상단의 **[Gemini 설정]** 버튼을 눌러 발급받은 Gemini API Key를 입력하면 실시간 AI 챗봇이 활성화됩니다. (키가 없어도 내장된 질의응답 기능으로 바로 테스트 가능합니다.)
